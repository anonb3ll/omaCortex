# Changelog

All notable changes to omaCortex are recorded here. The notes below are taken
from the GitHub releases. Dates are the release dates.

## [0.3.3] - 2026-11-21

- Pause window capture while Hyprland is sharing the screen
  ([#13](https://github.com/anonb3ll/omaCortex/pull/13)).
- Keep window capture paused when the connection to Hyprland drops and
  comes back during a screen share
  ([#17](https://github.com/anonb3ll/omaCortex/pull/17)).
- `install.sh` checks every value that goes into a download URL
  ([#14](https://github.com/anonb3ll/omaCortex/pull/14)).

**Full changelog:** [v0.3.2...v0.3.3](https://github.com/anonb3ll/omaCortex/compare/v0.3.2...v0.3.3)

## [0.3.2] - 2026-11-20
